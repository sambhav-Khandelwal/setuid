# SetuID

Worker-controlled work history and references: an interactive student research prototype.

## Open the website

https://sambhav-khandelwal.github.io/setuid/

GitHub Pages publishes `index.html` from the root of `main`. No build tools or dependencies are required. Future commits to `main` update the website automatically.

## Try it

1. Start guided setup and review the worker details.
2. Add relevant work experience and a hiring opportunity.
3. Prepare a reference request with worker permission; no message is sent automatically.
4. Record an actual contact outcome and any employer relationship evidence.
5. Choose the details for a named, expiring local preview.
6. Review the hirer view and record the next step.
7. Withdraw a preview or flag a reference correction.

## Scope

The initial profile is fictional demonstration data. Data entered by a visitor is saved only in that visitor's browser, using localStorage. It is not uploaded to GitHub or synchronized across devices. Sharing previews are demonstrations on the same device, not recipient-accessible web links. There are no live Rapido, Ola or Uber connections, logins, identity checks, payments or automatic messages.

The website is a working interactive prototype, not a production hiring service.
